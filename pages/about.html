About CryptoDash

CryptoDash is a real-time cryptocurrency dashboard that allows users to track live prices, analyze trends, and manage favorite coins easily.

🚀 Features

  • Live crypto price tracking
  • Interactive price charts
  • Favorites using LocalStorage
  • Top gainers & losers

🛠 Tech Stack

  • HTML, CSS, JavaScript
  • Chart.js for visualization
  • CoinGecko API

🎯 Purpose

Built as a fintech dashboard project to demonstrate API integration, real-time data handling, and frontend development skills.
